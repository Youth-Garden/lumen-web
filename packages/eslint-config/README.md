# @lumen/eslint-config

Shared ESLint configuration for the Lumen monorepo.

This package centralizes linting rules for Next.js, React, TypeScript, and standard JavaScript, ensuring code quality and stylistic consistency across all applications and packages.

## Usage

In your project's `.eslintrc.js` or `eslint.config.js`:

```json
{
  "extends": ["@lumen/eslint-config"]
}
```
